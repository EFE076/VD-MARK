# Autobedrijf Van der Mark — demo-website

Open `index.html` in een browser of gebruik de VS Code Live Server-extensie. De vijf pagina’s delen `css/style.css` en `js/main.js`. `js/occasions.js` bevat uitsluitend fictieve voorbeeldauto’s. Het contactformulier verzendt geen e-mail.

**Opmerking over huisstijl:** de bestaande site-inhoud en navigatiestructuur zijn onderzocht, maar de originele CSS/assets waren niet rechtstreeks uitleesbaar. Daarom gebruikt deze demo een voorlopige, ingetogen autobedrijf-stijl met rode accenten; voor een pixelnauwkeurige reproductie zijn screenshots of originele CSS nodig. Het logo is een tijdelijke tekstbehandeling. Illustraties zijn lokaal opgeslagen SVG’s en geen echte bedrijfsfoto’s.

Gecontroleerde bronpagina’s: https://www.autobedrijfvandermark.nl/ ; /wat-we-doen ; /wie-we-zijn ; /occasions ; /contact .
